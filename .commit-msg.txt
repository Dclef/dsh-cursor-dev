Mount without inject: read baseDir through ctx.get()

A real DSH boot failed the plugin fiber with:

  Error: cannot get property "baseDir" without inject
    at apply (lib/index.js:74:40)

Cordis guards service properties: reading ctx.baseDir throws unless the
service is declared in `inject`. ctx.get('baseDir') returns the value when
the host provides it and undefined otherwise, so the coding tool stays
mountable on hosts that do not.

The smoke test's fake ctx exposed baseDir as a plain property, which is why
19/19 passed while the real mount failed. The fake now throws the same
Cordis error unless baseDir is injected, so this class of bug cannot pass
the suite again.
