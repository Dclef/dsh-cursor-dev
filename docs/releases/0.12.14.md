# dsh-cursor-dev 0.12.14

> 发布日期：2026-11-23（Asia/Shanghai）。开发基线、兼容范围与依赖版本不变。

## 修复

- **Windows 用量面板误报未登录**：新版 Cursor CLI 把登录凭据迁移到 `auth.dpapi`，旧的 `auth.json` 可能只剩迁移标记。用量面板现在支持 Windows 当前用户的 DPAPI 凭据存储，并保留旧格式及显式 `CURSOR_AUTH_TOKEN` 的支持；无需重新登录或手填令牌。
- **切换 ACP / CLI 不再打断当前任务**：启动或执行中的任务保持原传输方式，等本轮结束后再切换。
- **无效模型会显示明确原因**：当 Cursor CLI 拒绝模型后在返回 ACP 错误前退出，错误会报告被拒绝的模型，不会输出完整模型列表或原始日志。

## 验证

- Windows 离线回归：329 项，319 通过、10 跳过、0 失败。用量路由和代理测试不再依赖本机 Cursor 登录或真实用量请求。
- 使用 Cursor CLI `2026.11.22-e9042b2` 验证无效模型诊断；在 Windows DSH 网页面板验证现有登录可以读取实际用量。

## 安装与升级

```sh
dsh plugin add dsh-cursor-dev@0.12.14
```

也可在 DSH 插件管理中更新当前 profile 的插件，或安装 GitHub Release 的 `dsh-cursor-dev-0.12.14.tgz` 附件。等待相关任务结束后，重启 DSH 或用支持换插件代码的 DSH 刷新功能加载新版本，再打开 Cursor 用量面板。
