# dsh-cursor-dev 0.12.11

> 发布日期：2026-11-03（Asia/Shanghai）。开发基线仍为 DSH 0.2.1-rc.5；兼容范围和依赖版本不变。

## 修复

- 修复执行通道已保存为 CLI、重新打开 Cursor 面板却显示 ACP 的问题；首屏数据和设置 GET 正确恢复已保存的通道。
- 修复重开后保存模型锁定等其他设置时，将旧 ACP 控件值写回文件的问题。
- 保留未保存的执行通道选择；语言等无关 POST 或模型列表刷新不会清掉草稿。仅当 transport 保存请求和响应均匹配当前草稿时，才确认保存完成。
- 模型探测完成后读取当前设置，避免迟到的 ACP 探测 GET 返回保存 CLI 之前的旧快照。
- 补齐设置路由到 SessionPool 的 transport 切换回调，让保存后的下一次调用采用新通道。升级后切换通道仍按现有约定关闭已有 Cursor 会话，请先等待正在执行的任务结束。
- 包含 0.12.10 的真实工具名称、参数、文件/命令输出及异常执行证据修复。升级必须作用于当前 profile 的实际安装副本；仅修改另一份源码不会更新后台。

## 验证

- Windows、DSH 0.2.1-rc.5 开发基线：309 项，299 通过、0 失败、0 取消、10 跳过。
- 10 项跳过为 3 项真实 Cursor/账户冒烟和 7 项 Windows 不适用的认证存储测试；不代表 macOS 已验收。
- 新增 8 项回归，覆盖首屏、重开、GET/POST、未保存草稿、模型缓存/延迟探测及真实插件挂载后的运行池切换。
- 同一组 54 项相关回归直接指向实际安装模块：旧 0.12.7 为 37 通过、17 失败，更新为包含本轮补丁的副本后全部通过；不把源码目录通过当作安装目录通过。
- 常规测试不启动真实 Cursor 或查询真实账户。仅显式设置 `DSH_CURSOR_LIVE_TESTS=1` 才启用真实冒烟。
- 详细记录见 [安装副本验收](../test/2026-11-03/cursor-runtime-install-and-transport.md)。离线测试及安装包验收不等同于运行中 GUI 已自动加载新代码。

## 安装与生效

- npm 来源：在 DSH 当前 profile 的插件管理中更新 `dsh-cursor-dev`；固定版本可使用 `dsh-cursor-dev@0.12.11`。
- Git/市场来源：更新 `Dclef/dsh-cursor-dev` 仓库来源。
- 固定快照：安装发布附件 `dsh-cursor-dev-0.12.11.tgz`。
- **等待运行任务完成，更新实际安装的插件，然后重启 DSH 并刷新页面。** 新代码作用于之后的新任务；历史日志中未保存的内容不会自动补齐。
