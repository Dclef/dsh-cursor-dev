# dsh-cursor-dev 0.12.10

> 发布日期：2026-11-03（Asia/Shanghai）。开发基线仍为 DSH 0.2.1-rc.5，兼容范围和依赖版本不变。

## 修复

- 子会话工具卡传递真实工具名称、请求参数、文件路径和执行输出，不再只显示 `cursor tool`、`{}` 和 `completed`；完成事件未重复提供参数时保留开始时的信息。
- CLI 无终态、非零退出、进程 Promise 拒绝或取消后，保留已经观察到的工具步骤、部分正文、实际文件改动和可续接会话，不再固定误报 `files changed: NONE`。
- 成功需要 CLI 明确成功终态及正常进程退出；取消/未确认完成的工具不会被标成成功。
- 无法扫描显示 `UNKNOWN`，不完整扫描显示 `PARTIAL`；缺失覆盖不推断新增或删除，已观察到的修改继续保留。
- 缺少 `started`、只有完成事件的工具也进入父报告时间线。
- 失败信息保留已知退出码、终止信号、stderr 尾部与持久化警告；不是把上游 CLI 的异常当成成功，也不自动重跑可能有副作用的任务。

## 验证

- Windows、DSH 0.2.1-rc.5 开发基线：301 项，291 通过、0 失败、10 跳过。
- 跳过的 10 项为 3 项真实 Cursor/账号冒烟和 7 项不适用 Windows 的认证存储场景，不代表 macOS 已验证。
- 默认 `npm test` 不启动真实 Cursor 或查询真实账户额度，保留本地 HTTP/协议模拟。只有明确设置 `DSH_CURSOR_LIVE_TESTS=1` 才启用真实冒烟，届时可能消耗账号额度。
- 包含真实 CLI 解析器到真实子会话镜像的离线接通测试、取消/进程异常、失败后落盘证据、扫描完整性和工具时间线回归。

## 安装与生效

- npm 来源：在 DSH 插件管理中更新 `dsh-cursor-dev`；需要固定版本时可指定 `dsh-cursor-dev@0.12.10`。
- Git/市场来源：更新 `Dclef/dsh-cursor-dev` 仓库来源。
- 固定快照：使用本次发布的 `dsh-cursor-dev-0.12.10.tgz`。
- **更新当前 profile 实际加载的插件后，重启 DSH 并刷新页面。** 只更新另一份源码、只刷新浏览器，不能保证后台代码生效。
- 不改模型偏好、会话配置、兼容范围或旧日志；历史日志里从未保存的工具参数/输出不会凭空补齐。

本次没有自动重启用户当前 DSH，离线回归及安装包检查不等同于当前桌面 GUI 重启后的实机验收。
