# dsh-cursor-dev 0.12.12

> 发布日期：2026-11-11（Asia/Shanghai）。开发基线仍为 DSH 0.2.1-rc.5；兼容范围和依赖版本不变。

## 优化

- 额度查询与 Cursor 子进程共用面板保存的代理：`UsageClient` 支持每次请求读取动态代理，`index.js` 接入 `resolveChildProxy(readSettings(dataDir).proxy)`。保存代理后下一次额度请求即生效，不再独立探测系统代理；原有固定代理与一次性探测接口保持兼容。
- 合并并发模型刷新：同一数据目录与执行通道（ACP / CLI）的刷新共享一个进行中的 Promise，强制刷新也加入同一请求，避免一次打开面板同时启动多个 CLI 探测进程；ACP 与 CLI 的模型命名空间仍严格隔离。
- 工作区变更扫描提速：任务前后的文件指纹从逐文件串行 `stat` 改为每批最多 16 个并发，保留文件上限、跳过目录规则与「扫描不完整不得误报删除/新增」的语义。
- 续聊索引失败可观测：`ConversationIndex` 记录读写失败并在成功写入后清除，工具结果与状态接口新增 `persistenceWarning`；写入失败不再静默导致重启后续聊丢失，也不会让编码任务失败或卡死写队列。

## 验证

- Windows、DSH 0.2.1-rc.5 开发基线：310 项，303 通过、0 失败、0 取消、7 跳过。
- 7 项跳过为 Windows 平台上不适用的认证存储测试；不代表 macOS 已验收。
- 新增 4 项回归：动态代理随请求变化、`index.js` 实际接线的代理形状与 `describeProxy` 一致、并发模型刷新仅启动一次 CLI 探测、ACP 与 CLI 刷新不共用 Promise。
- `git diff --check` 无格式问题。常规测试不启动真实 Cursor 或查询真实账户；仅显式设置 `DSH_CURSOR_LIVE_TESTS=1` 才启用真实冒烟。
- 离线测试通过不等同于运行中 GUI 已自动加载新代码；需更新实际安装副本并重启 DSH。

## 安装与生效

- npm 来源：在 DSH 当前 profile 的插件管理中更新 `dsh-cursor-dev`；固定版本可使用 `dsh-cursor-dev@0.12.12`。
- Git/市场来源：更新 `Dclef/dsh-cursor-dev` 仓库来源。
- 固定快照：安装发布附件 `dsh-cursor-dev-0.12.12.tgz`。
- **等待运行任务完成，更新实际安装的插件，然后重启 DSH 并刷新页面。** 新代码作用于之后的新任务；历史日志中未保存的内容不会自动补齐。
